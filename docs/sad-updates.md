# Updates to carry into the SAD

These are the changes from the project's updates that the SAD document should say.

## §4.7 UI design (UI G1, October 31, 2026)
The interface follows a modern admin-dashboard layout, inspired by Gentelella v4 and implemented in custom CSS. It has a collapsible dark sidebar, a top bar with search and notifications, cards and status pills, in AGILE's maroon and gold with IBM Plex fonts.

The technology stack does not change: PHP 8 views, custom CSS, vanilla JavaScript and self-hosted Chart.js, with no build step. No Gentelella code is used.
